中学 3 年 数学 ／ 二次方程式

二次方程式ラボax²＋bx＋c＝0

二次方程式の解き方は、①平方根を使う ②因数分解を使う ③解の公式を使う、の 3 つです。どれを使えばよいかを見分けられれば、計算はぐっと楽になります。数を動かしながら、一つずつ確かめていきましょう。

01

二次方程式の「解」ってなに？

x に数を入れて、式の値がちょうど 0 になる数が「解」。二次方程式の解は、ふつう 2 つあります。

方程式 x² − 5x + 6 = 0 の x に、数を入れてみよう。

おさえておくこと

・二次方程式：移項して整理すると ax² + bx + c = 0（a ≠ 0）の形になる方程式。

・解：方程式を成り立たせる x の値。すべての解を求めることを「方程式を解く」という。

・上の式では x = 2 と x = 3 の 2 つが解。答えは「x = 2, 3」のように書く。

解が求まったら、もとの式に代入して 0 になるかを確かめると、計算ミスに気づけます。

02

平方根を使って解く

「□² ＝ 数」の形になっていれば、□ は「その数の平方根」。プラスとマイナスの 2 つを忘れずに。

① ax² ＝ b の形

3x² − 48 = 0
3x² = 48−48 を移項
x² = 16両辺を 3 でわる
x = ±416 の平方根は 4 と −4
x² = 12
x = ±√12
x = ±2√3√12 = √(4×3) = 2√3 と簡単にする

② (x ＋ m)² ＝ n の形

かっこの中をひとまとまり（□）と見て、□ ＝ ±√n。

(x − 3)² = 5
x − 3 = ±√5x − 3 を □ と見る
x = 3 ± √5−3 を移項
(x + 1)² = 9
x + 1 = ±3
x = −1 ± 3
x = 2, −4−1 + 3 = 2、−1 − 3 = −4 と 2 つに分ける

注意：x² = 16 の答えを x = 4 だけにしない。(−4)² も 16 なので、x = ±4。

03

因数分解を使って解く

A × B ＝ 0 なら、A ＝ 0 か B ＝ 0。左辺を「かけ算の形」にできれば、あとは一次方程式を 2 つ解くだけ。

和と積で探す：x² ＋ px ＋ q ＝ (x ＋ ●)(x ＋ ▲)

「かけて q、たして p」になる 2 つの数 ●、▲ を探します。p と q を変えてみよう。

x² +x += 0
共通因数でくくるx² − 5x = 0x(x − 5) = 0x = 0, 5
和と積x² + x − 6 = 0(x + 3)(x − 2) = 0x = −3, 2
a² − b² ＝ (a＋b)(a−b)x² − 49 = 0(x + 7)(x − 7) = 0x = ±7
(a ± b)² の形x² − 8x + 16 = 0(x − 4)² = 0x = 4（解は 1 つ）

符号に注意：(x + 3)(x − 2) = 0 の解は x = −3, 2。かっこの中の数と符号が反対になります。

04

平方完成：(x ＋ ○)² の形をつくる

因数分解できない式も、「x の係数の半分の 2 乗」を両辺に足すと、(x ＋ ○)² ＝ 数 の形になり、平方根で解けます。

面積で見る：x² ＋ bx に何を足せば正方形？

例：x² ＋ 6x − 7 ＝ 0

x² + 6x = 7数の項を右辺へ移項
x² + 6x + 9 = 7 + 96 の半分 3 の 2 乗 = 9 を両辺に足す
(x + 3)² = 16左辺は (x + 3)² になる
x + 3 = ±4
x = 1, −7−3 + 4 = 1、−3 − 4 = −7

この方法を、どんな a, b, c でもできるように一般化したものが、次の解の公式です。

05

解の公式

どんな二次方程式でも、a, b, c を代入すれば解ける「最後の手段」。最後に √ の中と約分を必ず簡単にします。

x ＝ −b ± b² − 4ac2a

a, b, c を入れて、代入の手順を見る

ミスしやすいところ：① b が負のとき −b は正になる（b ＝ −5 なら −b ＝ 5）。② b² は (−5)² ＝ 25 のように符号ごと 2 乗。③ 分母の 2a は分子全体にかかるので、約分は分子のすべての項をわれる数で行う。

06

どの解き方を使う？

上から順にチェックすると、いちばん楽な方法が選べます。

かっこを展開し、移項して「＝ 0」の形に整理する
x(x + 2) = 15 → x² + 2x − 15 = 0　／　係数に共通な数があれば、両辺をわって小さくする
「□² ＝ 数」の形？ → 平方根
x² = 7 → x = ±√7　／　(x − 2)² = 3 → x = 2 ± √3
共通因数でくくれる？ 和と積で因数分解できる？ → 因数分解
x² − 3x = 0 → x(x − 3) = 0　／　x² − 7x + 12 = 0 → (x − 3)(x − 4) = 0
どれもできない → 解の公式
x² + 3x + 1 = 0 → x = (−3 ± √5) / 2
07

よくある間違い

テストで点を落としやすいところ。

✕ x² = 3x → 両辺を x でわって x = 3○ x² − 3x = 0 → x(x − 3) = 0 → x = 0, 3

x でわると、x ＝ 0 の解が消えてしまう。文字でわらずに移項してくくる。

✕ (x − 5)(x + 2) = 0 → x = −5, 2○ x = 5, −2

x − 5 ＝ 0 から x ＝ 5。かっこの中の数と符号が反対になる。

✕ (x − 2)(x − 3) = 6 → x − 2 = 6, x − 3 = 6○ 展開して x² − 5x = 0 → x = 0, 5

「かけて 0」だから片方が 0 といえる。右辺が 0 でないときは使えない。

✕ (2 ± 4√3) / 2 = 1 ± 4√3○ (2 ± 4√3) / 2 = 1 ± 2√3

約分は分子のすべての項を 2 でわる。

✕ x² − 6x + 2 = 0 の b² − 4ac を −36 − 8○ (−6)² − 4×1×2 = 36 − 8 = 28

b が負でも b² は正。かっこをつけて代入する。

✕ x = ±√20 のまま○ x = ±2√5

√ の中はできるだけ小さい自然数にする（√20 ＝ √(4×5) ＝ 2√5）。

09
