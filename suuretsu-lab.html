01

等差数列

第1項から第n項まで、足す回数は n − 1 回。

ここがポイントan は「n 番目の値」。n 個の和ではありません。初項にはまだ d を足していないので、一般項は a + (n − 1)d。

02

等差数列の和

逆順に並べたもう1列を足すと、どのペアも同じ値。

初項 2、公差 3 の数列で実験。

ここがポイントペアを作るために同じ和を2回使っています。n が奇数でも公式は同じ。Sn = n(a + an)2。

03

等比数列

掛ける数が一定。負の公比では、正と負を行き来する。

ここがポイント一般項は an = arn−1。指数もn − 1です。r = 0 の場合、第1項は a、第2項以降は 0 として考えます。

04

等比数列の和

公比を掛けた和を1つずらすと、途中の項が消える。

Sn = a + ar + … + arn−1
rSn = ar + … + arn
(1 − r)Sn = a(1 − rn)
Sn = a(1 − rn)1 − r　(r ≠ 1)

ここがポイント上の公式は r ≠ 1 のときだけ。r = 1 なら全項が a なので Sn = na。03 の公比を 1 にして、確かめよう。

05

Σの計算

Σ は「指定された番号の項を、全部足す」という合図。

ここがポイントk は代入する番号。m から n まではn − m + 1 個です。開始番号を変えると、終了番号も必要に応じて調整されます。Σ3 は 3 ではなく「3 × 項数」。

基本公式（k = 1 から n）

nΣk = 1k = n(n + 1)2
nΣk = 1k² = n(n + 1)(2n + 1)6
nΣk = 1k³ = (n(n + 1)2)²

式を分ける・不要な部分を引く

nΣk = 1(2k + 1) = 2nΣk = 1k + n

nΣk = mk² = nΣk = 1k² − m − 1Σk = 1k²

m = 1 のとき、引く部分の和は 0。Σ の中の定数も項数分だけ足します。

06

確認問題

基礎 → 標準 → 入試。選ぶとすぐに、正解と理由が表示されます。

入試レベルは、この教材のために作成したオリジナル問題です。

ここがポイント間違えたら、答えだけでなく初項・公差／公比・項数のどこを取り違えたかを確認。選び直して復習できます。

07

問題を解くときのポイント

規則を見抜く → 求めるものを決める → 条件を整理する。

  1. 最初の3項を書く差が一定？ 比が一定？
  2. 「項」か「和」か確認an と Sn を区別。
  3. 項数を数えて代入m 番目から n 番目は n − m + 1 個。
  4. 小さい数で検算n = 1、2 で式が合うか確かめる。

公式の使い分け表

見分け方・目的使う公式確認すること
同じ数を足すan = a + (n − 1)d差が一定か確認
等差の和Sn = n{2a + (n − 1)d}2初項・末項・項数を整理
同じ数を掛けるan = arn−1前の項が0でないとき、比を確認
等比の和Sn = a(1 − rn)1 − rr ≠ 1。r = 1 なら na
Σ の計算一次式・二次式などに分解開始番号と終了番号に注意

よくあるミス

  • a + nd と書く → 足す回数は n − 1。
  • 和の公式の rn を rn−1 にする → 一般項と混同しない。
  • Σ の定数を1回しか足さない → 項数を掛ける。
  • Σ の上の数字だけを項数にする → 開始番号も見る。

入試につながる考え方

和 Sn から項を求めるなら、隣どうしの差。

a₁ = S₁
an = Sn − Sn−1 （n ≧ 2）

n = 1 は別に確認。差で出した式が初項にも使えるとは限りません。

ここがポイント公式を選ぶ前に「何を、何個、足すのか」を短く書こう。規則が見えない数列に、等差・等比の公式を無理に当てはめないこと。
