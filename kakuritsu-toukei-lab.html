03

分散・標準偏差：散らばりを測る

分散は「平均からのずれの2乗」の平均。標準偏差は分散の平方根。

平均50点でも、全員が50点のクラスと、0点・100点に分かれたクラスは違います。その違いが「散らばり」です。

  1. 平均 μ = E(X) を出す。μ は「ミュー」と読み、平均の略記です。
  2. 各値のずれ X − μ を2乗し、確率を掛けて合計する。これが分散 V(X)。
  3. 平方根を取った σ(X) = √V(X) が標準偏差。「シグマ」と読み、元の値と同じ単位になる。
V(X) = E((X − μ)²) = E(X²) − {E(X)}²
σ(X) = √V(X)
計算の型：X・P・XP・X²P の4行を作る

04

独立：別々の結果を組み合わせる

独立とは、一方の結果を知っても、もう一方の確率が変わらないこと。

独立の判定：P(AかつB) = P(A)P(B)。例えば別々に投げる公平なサイコロとコインは、通常、独立と考えます。

列はサイコロ1〜6。上段が表、下段が裏。緑は条件に合う組。

求めたい量公式使える条件
和の期待値E(X + Y) = E(X) + E(Y)不要
積の期待値E(XY) = E(X)E(Y)独立なら使える
和・差の分散V(X ± Y) = V(X) + V(Y)独立なら使える
aX + bY の分散a²V(X) + b²V(Y)独立なら使える
「戻す」と「戻さない」の違い

球を戻して、よく混ぜてから次を引くなら、次の袋の中身は同じ。繰り返しは独立と考えられます。戻さずに次を引くと、袋の中身が変わるため、一般に独立ではありません。

ただし、1回に3個同時に引いて全部戻す試行を2回行うなら、1回目の個数と2回目の個数は独立です。

ここがポイント「別の文字X、Yだから独立」とは限りません。独立でなくても期待値の和は使えます。分散の差は、独立なら引き算でなく足し算。

二項分布：成功した回数を数える

同じ成功確率pの試行を、独立にn回。その成功回数Xを数える。

「成功」は問題で決めた結果のこと。表、赤球、当たりなど、好きな結果を成功と呼べます。

X は B(n, p) に従う
P(X = k) = nCkpk(1 − p)n−k
E(X) = np　　V(X) = np(1 − p)
  1. 何を「1回の試行」にするか決める。
  2. 1回で成功する確率 p と、繰り返す回数 n を分ける。
  3. 成功k回の並べ方 nCk × 1つの並びの確率 pᵏ(1−p)ⁿ⁻ᵏ。
例題：「コイン4枚で表1枚」を3回試す

1回の試行は「コイン4枚を投げること」。表が1枚の確率は 4C1(12)⁴ = 14。これを3回繰り返すので、成功回数は B(3, 14)。

P(X = 2) = 3C2(14)²(34) = 964

ここがポイント「球を同時に数個取り出す」は、その中の成功が独立ではないため、そのまま二項分布にはできません。戻すかどうか、何を1回とするかが出発点。

06

連続型：確率はグラフの面積

待ち時間のように細かく値が変わるときは、棒から「面積」へ。

確率密度 f(x)は面積を作るための高さ。P(a ≦ X ≦ b) は a から b までのグラフの下の面積です。全体の面積は1。

端を交差させたときは、もう一方を合わせます。

  1. 長方形なら「幅 × 高さ」。12分おきの待ち時間は f(x) = 112（0 ≦ x ≦ 12）、それ以外は0。
  2. f(x) = x2 の0からtまでなら、三角形の面積 t × t22 = t²4。
  3. aからbまでなら「0からbまで」−「0からaまで」。数学Ⅱの積分でも同じ面積を求められます。
連続型の平均・分散も、考え方は同じ
E(X) = ∫ x f(x) dx
E(X²) = ∫ x² f(x) dx
V(X) = E(X²) − {E(X)}²

∫（積分）は細い面積を全部足す記号。計算に慣れる前は、図形の面積や次の一様分布の公式で進めます。

一様分布 [a, b]： E(X) = a + b2、V(X) = (b − a)²12

例えば [1,8] なら E(X)=4.5、V(X)=4912。

ここがポイント連続型では P(X = 3) = 0。1点には横幅がないためです。f(3) が0でなくても、「高さ」と「確率」は違います。

正規分布：平均からの距離に直す

正規分布は左右対称の山。平均から何個分の標準偏差だけ離れたかで読む。

N(μ, σ²)の1つ目は平均、2つ目は分散。N(25,4)なら平均25、標準偏差2です。
Z = X − μσ　→　Z は N(0,1) に従う

平均25・標準偏差2の山。区間を動かして、面積を確かめよう。

  1. まず σ = √分散 を求める。
  2. X の上下の境目を、それぞれ (境目 − μ) ÷ σ に直す。
  3. 標準正規分布表を読み、必要な面積を足す・引く。

標準化＝「標準偏差の何個分？」に直す

08

二項分布を正規分布で近似する

繰り返しが多い二項分布の棒は、正規分布の山で近似できる。

B(n,p) ≈ N(np, np(1−p))
Z = X − np√{np(1−p)}

npとn(1−p)がともに十分大きいときに使います。この章の問題では十分大きい設定です。

例題：コイン2500回で、表が1320回以上
  1. Xを表の回数とする。XはB(2500, 12)。
  2. 平均は1250、分散は625、標準偏差は25。
  3. 境目を標準化：(1320−1250)÷25 = 2.8。
  4. P(X ≧ 1320) ≈ P(Z ≧ 2.8) = 0.5 − 0.4974 = 0.0026。約0.26%。
連続補正：回数を滑らかな面積で置き換えるとき、X≧1320を1319.5以上とすると精度を改善できます。本教材の問題解説は学校の表を用いる基本計算（補正なし）を先に示し、必要な箇所で補足します。

ここがポイント近似なのに「=」で完全に同じとしないこと。平均と分散を先に計算し、分母は必ず標準偏差にします。

09

標本調査：一部から全体を考える

調べたい全体が母集団。その一部として選んだものが標本。

無作為抽出は、都合のよい相手を選ばず、対象からランダムに選ぶこと。人数だけ増やしても、選び方の偏りは消えません。
ことば意味
母平均 μ・母標準偏差 σ全体の平均と散らばり
標本の大きさ n選んだ人数・個数
標本平均 X̄選ばれるn個の平均。標本を変えると値も変わる
標本平均の観測値 x̄実際に調べて得られた平均の数値
X̄ = X₁ + … + Xₙn
E(X̄) = μ　　V(X̄) = σ²n　　σ(X̄) = σ√n

紫：個々の値（σ=3）。緑：n個の標本平均。曲線は見比べやすいよう、それぞれ山の高さをそろえています。

なぜ標準偏差を√nで割る？
  1. 独立なn個の和の分散は nσ²。
  2. 平均は和をnで割るため、分散はn²で割る。nσ² ÷ n² = σ²n。
  3. 平方根を取ると σ√n。この標本平均の標準偏差を標準誤差とも呼びます。

母集団が正規分布なら、標本平均も正規分布。そうでなくても、独立な同じ分布からの標本でnが十分大きければ、標本平均を正規分布で近似できます。

ここがポイントここでの公式は独立な抽出（復元抽出、または母集団が十分大きい場合）を前提にします。σとσ√nは「個人の散らばり」と「平均の散らばり」で別物。

10

推定：平均や割合を幅で答える

1つの数で決めつけず、「この範囲」と答えるのが区間推定。

標本平均のまわりに「誤差の幅」を付けます。95%信頼区間では、標準誤差を1.96倍した幅を左右に付けます。

母集団が正規分布でσが既知の場合、または十分大きい標本による正規近似で使う式です。

母平均の95%信頼区間： x̄ ± 1.96 × σ√n
σが不明でnが十分大きいとき：σを標本の標準偏差sで近似

標本平均65.4、標準偏差7.2として比較。nが小さい設定は「幅の変わり方」の説明用です。

添付問題の例：n=100、平均65.4、標準偏差7.2
  1. 標準誤差：7.2 ÷ √100 = 0.72。
  2. 誤差の片幅：1.96 × 0.72 = 1.4112。
  3. 下端63.9888、上端66.8112。小数第3位を四捨五入すると [63.99, 66.81]。

95%は「区間を作る方法」の成績

同じ調べ方で標本を取り直して、区間を100本作ったとします。そのうち約95本が、本当の母平均を捕まえるイメージです。母平均が動くのではなく、標本と区間が毎回変わります。

「個々の点数の95%が入る範囲」ではありません。

割合を推定するとき

p̂（ピー・ハット）は標本の成功割合。「成功した個数 ÷ 調べた個数」です。

母比率の95%信頼区間：p̂ ± 1.96√{p̂(1−p̂)n}

この正規近似はnが十分大きく、成功・失敗の両方が十分あるとき。小標本・0や1に近い割合では別の方法が必要です。

必要な人数を決める：区間の全幅を0.02以下にしたい
  1. 割合を0.5と見積もる。全幅は「片幅の2倍」。
  2. 2 × 1.96√{0.5×0.5n} ≦ 0.02。
  3. √n ≧ 98 なので n ≧ 9604。人数は整数なので端数が出たら切り上げます。

ここがポイント95%とは、この方法で標本を取り直して区間を作ると、約95%の区間が真の値を含むという意味。個々のデータの95%が入る範囲ではありません。

検定：偶然では説明しにくい？

「もとの仮定が正しい」として、今回のずれがどれほど珍しいかを調べる。

棄却（ききゃく）は、仮定H₀を採用しないという判断。有意水準5%は、H₀が正しいのに誤って棄却する確率を5%に設定することです。正規分布では、両側に2.5%ずつ残す境界が±1.96、右だけに5%残す境界が約1.645です。

添付の最後の2題を解くための章です。「平均との差がある」と「偶然の範囲を超える差がある」を区別します。

  1. 帰無仮説（きむかせつ）H₀を置く。「母平均140g」「母比率0.30」など、いったん正しいとする値。
  2. 対立仮説（たいりつかせつ）H₁を決める。「違う」なら両側、「大きい」なら上側。データを見る前に決める。
  3. 標準化して、ずれZを求める。
  4. 有意水準5%の境界と比べる。両側なら|Z|≧1.96、上側ならZ≧1.645を目安にH₀を棄却する。
状況標準化
母平均の検定（σ既知、または大標本近似）x̄ − μ₀s√n（σ既知ならsをσに）
母比率の検定p̂ − p₀√{p₀(1−p₀)n}

緑が「まれな領域」。橙の線が今回のZです。

例題：ハンバーガーは平均140gより重い？
  1. H₀：μ=140、H₁：μ>140。上側検定を使う。
  2. n=121、x̄=141.2、s=7.2。標準誤差は 7.2÷11。

01　確率分布・期待値・分散　4題

対応：01〜03章。PDFと同じ問題を確認できます。

  1. 基礎 確率の表を読む

    X は 0、1、2 をそれぞれ確率 0.25、0.50、0.25 で取る。①確率の合計 ②P(X≧1) ③E(X) を求めよう。

    ヒント

    どの値が条件に当てはまるか、丸を付けよう。

    解答・考え方

    ① 0.25＋0.50＋0.25＝1。
    ② 1と2をまとめるので、0.50＋0.25＝0.75。
    ③ E(X)＝0×0.25＋1×0.50＋2×0.25＝1。

    値に、その値の確率を掛けてから足す。

  2. 基礎 E・V・σを一緒に出す

    X は 2点と6点を同じ確率で取る。E(X)、V(X)、σ(X) を、単位も付けて求めよう。

    ヒント

    まず平均を出してから、平均との差を調べる。

    解答・考え方

    E(X)＝(2＋6)÷2＝4点。
    ずれは −2点、＋2点。その2乗はどちらも4点²。
    V(X)＝4点²、σ(X)＝√4＝2点。

    分散は点²、標準偏差は元と同じ点の単位。

  3. 標準 出やすさが違うとき

    X は 0、2、5 をそれぞれ確率 0.5、0.3、0.2 で取る。E(X)、E(X²)、V(X) を求めよう。

    ヒント

    E(X²) は「値だけ2乗」して、確率を掛ける。

    解答・考え方

    E(X)＝0×0.5＋2×0.3＋5×0.2＝1.6。
    E(X²)＝0²×0.5＋2²×0.3＋5²×0.2＝6.2。
    V(X)＝6.2−1.6²＝3.64。

    E(X²) と {E(X)}² は違う。確率は2乗しない。

  4. 応用 点数を変換する

    E(X)＝4、V(X)＝4 とする。Y＝3X−2 のとき、E(Y)、V(Y)、σ(Y) を求めよう。

    ヒント

    全員に同じ数を足しても、散らばりは変わらない。

    解答・考え方

    E(Y)＝3×4−2＝10。
    V(Y)＝3²×4＝36。−2は分散に影響しない。
    σ(Y)＝√36＝6。

    平均は3倍して−2。分散は3²倍。標準偏差は3倍。

02　独立・二項分布　4題

対応：04〜05章。PDFと同じ問題を確認できます。

  1. 基礎 独立な2つの量

    X と Y は独立。E(X)＝2、E(Y)＝3、V(X)＝1、V(Y)＝4。①E(XY) ②E(2X−Y) ③V(2X−Y) を求めよう。

    ヒント

    和や差の分散では、係数を2乗する。

    解答・考え方

    ① 独立なので E(XY)＝2×3＝6。
    ② E(2X−Y)＝2×2−3＝1。
    ③ V(2X−Y)＝2²×1＋(−1)²×4＝8。

    差でも分散は足す。独立という条件を確認。

  2. 基礎 ちょうど2回成功

    公平なコインを独立に6回投げる。表がちょうど2回出る確率を求めよう。

    ヒント

    表2回を置く場所は何通り？

    解答・考え方

    表2回の場所は ₆C₂＝6×5÷(2×1)＝15通り。
    1つの並びの確率は 0.5⁶。
    求める確率＝15×0.5⁶＝0.234375。

    「1つの並び」だけで終わらず、並べ方を掛ける。

  3. 標準 二項分布の平均と分散

    1回の成功確率が0.2の試行を、独立に20回行う。成功回数Xの分布、E(X)、V(X)、σ(X) を求めよう。

    ヒント

    n＝回数、p＝1回の成功確率。

    解答・考え方

    X は B(20, 0.2) に従う。
    E(X)＝20×0.2＝4。
    V(X)＝20×0.2×0.8＝3.2、σ(X)＝√3.2。

    分散は np(1−p)。np は平均。

  4. 応用 少なくとも1回

    1回の当たり確率が0.2のくじを、毎回戻して独立に5回引く。少なくとも1回当たる確率を求めよう。

    ヒント

    反対の出来事は「5回とも外れ」。

    解答・考え方

    1回の外れ確率は 1−0.2＝0.8。
    5回とも外れる確率＝0.8⁵＝0.32768。
    1回以上当たる確率＝1−0.32768＝0.67232。

    「少なくとも」は反対側を数えると短くなる。

03　連続型・正規分布　4題

対応：06〜08章。PDFと同じ問題を確認できます。

  1. 基礎 高さではなく面積

    待ち時間X（分）は0〜10の一様分布に従う。①密度の高さ ②P(3≦X≦7) ③P(X＝5) を求めよう。

    ヒント

    長方形全体の面積が1になる。

    解答・考え方

    ① 横幅10×高さ＝1 より、高さは0.1。
    ② 幅は7−3＝4。確率＝4×0.1＝0.4。
    ③ 1点の横幅は0なので、P(X＝5)＝0。

    高さ0.1を、その点の確率と取り違えない。

  2. 基礎 Nの2つ目は何？

    X は N(50,16) に従う。①平均・分散・標準偏差 ②X＝58のときのZ ③P(X≧58) を求めよう。

    ヒント

    標準化は「平均との差 ÷ 標準偏差」。

    解答・考え方

    ① 平均50、分散16、標準偏差√16＝4。
    ② Z＝(58−50)÷4＝2。
    ③ 右側の面積＝0.5−0.4772＝0.0228。

    標準化で割るのは16ではなく4。

  3. 標準 平均をまたぐ区間

    X は N(50,16) に従う。P(46≦X≦56) を求めよう。

    ヒント

    両端をZに直し、左と右の面積を足す。

    解答・考え方

    46のZ＝(46−50)÷4＝−1。56のZ＝1.5。
    P(−1≦Z≦0)＝A(1)＝0.3413。
    求める確率＝0.3413＋0.4332＝0.7745。

    平均の左右に分かれる区間は、2つの面積を足す。

  4. 応用 回数を正規分布で近似

    公平なコインを独立に400回投げ、表の回数をXとする。正規近似（連続補正なし）で P(X≧220) を求めよう。

    ヒント

    B(n,p) の平均と分散から、正規分布を作る。

    解答・考え方

    X は B(400, 0.5)。平均200、分散100、標準偏差10。
    N(200,100) で近似。境目のZ＝(220−200)÷10＝2。
    確率は約 0.5−0.4772＝0.0228。

    近似なので「約」を付ける。今回は補正なしの指定。

04　標本平均・区間推定　4題

対応：09〜10章。PDFと同じ問題を確認できます。

  1. 基礎 1人と36人の平均

    母平均60、母標準偏差12の正規母集団から独立に36個を抽出する。標本平均 X̄ の期待値・分散・標準偏差を求めよう。

    ヒント

    平均の散らばりは、個々の散らばりより小さい。

    解答・考え方

    E(X̄)＝60。平均の中心は母平均と同じ。
    V(X̄)＝12²÷36＝4。
    σ(X̄)＝12÷√36＝2。

    標本平均の標準偏差（標準誤差）は σ÷√n。

  2. 基礎 人数を4倍にしたら

    母標準偏差は同じまま、標本の大きさを36から144にする。標本平均の標準偏差は何倍になるか。

    ヒント

    比を考えれば、母標準偏差の値は不要。

    解答・考え方

    標本の大きさは 144÷36＝4倍。
    √n は2倍になる。
    σ÷√n は半分になるので、0.5倍。

    人数4倍で、標準誤差は4分の1ではなく半分。

  3. 標準 母平均の95%信頼区間

    母標準偏差10が既知の正規母集団から独立に100個を抽出し、標本平均102を得た。母平均の95%信頼区間を求めよう。

    ヒント

    標本平均を中心に、誤差の片幅を左右に付ける。

    解答・考え方

    標準誤差＝10÷√100＝1。
    誤差の片幅＝1.96×1＝1.96。
    95%信頼区間は [102−1.96, 102＋1.96]＝[100.04, 103.96]。

    片幅1.96に対して、区間の全幅は3.92。

  4. 応用 母比率の95%信頼区間

    十分大きい集団から無作為に400人を調べ、100人が賛成した。独立な標本とみなして、賛成する母比率の95%信頼区間を正規近似で求めよう（小数第3位まで）。

    ヒント

    標本の割合 p̂＝賛成人数÷標本の大きさ。

    解答・考え方

    p̂＝100÷400＝0.25。
    標準誤差＝√{0.25×0.75÷400} ≈ 0.02165。
    0.25±1.96×0.02165 より、約 [0.208, 0.292]。

    途中では丸めすぎない。最後に小数第3位に丸める。

μ・σ・n・p・X̄も確認する
μ（ミュー）
母平均。分布の中心。E(X)をμと書くこともあります。
σ（シグマ）・σ²
σは標準偏差、σ²は分散。大文字のΣ（全部足す）とは別の記号。
n・p
二項分布ではnは繰り返す回数、pは1回の成功確率。標本調査ではnは調べる人数・個数。
X̄（エックス・バー）
n個の平均。E(X̄)は「平均の中心」、V(X̄)は「平均の分散」、σ(X̄)は「平均の標準偏差（標準誤差）」。
p̂（ピー・ハット）
実際に調べた標本の成功割合。成功数÷標本の大きさ。

閉じると、読んでいた位置でそのまま続けられます。
