まず、確率と記号に慣れよう

確率は「起こりやすさ」を、0から1までの数で表したもの。

10回のうち3回くらい起こるなら、確率は 310 = 0.3 = 30%。コインなど有限個の結果では、0は起こらない、1は必ず起こる、を表します。

X ≧ 2 / X ≦ 22以上 / 2以下2そのものも含む
E(X)、V(X)、σ(X)平均、分散、標準偏差詳しくは02・03章

Σ（シグマ）並んだものを全部足すΣxp は「値×確率」の合計
場合の数：足す？ 掛ける？
  1. 別々の場合をまとめるときは足す。サイコロで1または2なら、16 + 16。
  2. 組み合わせて順に行うときは掛ける。サイコロ6通りとコイン2通りの組は 6 × 2 = 12 通り。
  3. 確率を「当てはまる場合 ÷ 全部の場合」で計算するには、各場合が同じくらい起こりやすい必要があります。
組合せ C：順番を区別しない選び方

5人から2人を選ぶ。最初は5通り、次は4通り。でも「A→B」と「B→A」は同じ組なので2で割る。

5C2 = 5 × 42 × 1 = 10

一般に nCr = n(n−1)…(n−r+1)r(r−1)…1。0個選ぶ方法は1通りなので nC0 = 1。

n! は n×(n−1)×…×1。0! = 1 と約束します。

ここがポイント「少なくとも1回」は「0回ではない」。P(X ≧ 1) = 1 − P(X = 0) にすると楽なことが多い。

期待値：出やすさ込みの平均

期待値は、何度も繰り返したときの平均の目安。必ず出る値ではない。

出る値 × その確率を全部足します。出やすい値ほど、平均を強く引っ張ります。
E(X) = x₁p₁ + x₂p₂ + … = Σxp

0点・1点・2点のくじが入った袋。各くじの枚数を変えてみよう。

例題：コイン3枚の表の枚数
X0123
P18383818
E(X) = 0 × 18 + 1 × 38 + 2 × 38 + 3 × 18 = 32

1.5枚という結果は出ませんが、平均なら1.5枚になれます。

ここがポイント値の単純平均にしてよいのは、各値の確率が等しいときだけ。賞金問題では「0円になる場合」も表に入れます。

03

分散・標準偏差：散らばりを測る

分散は「平均からのずれの2乗」の平均。標準偏差は分散の平方根。

平均50点でも、全員が50点のクラスと、0点・100点に分かれたクラスは違います。その違いが「散らばり」です。

  1. 平均 μ = E(X) を出す。μ は「ミュー」と読み、平均の略記です。
  2. 各値のずれ X − μ を2乗し、確率を掛けて合計する。これが分散 V(X)。
  3. 平方根を取った σ(X) = √V(X) が標準偏差。「シグマ」と読み、元の値と同じ単位になる。
V(X) = E((X − μ)²) = E(X²) − {E(X)}²
σ(X) = √V(X)
計算の型：X・P・XP・X²P の4行を作る

P271737171
XP0176737107
X²P01712797227
V(X) = 227 − (107)² = 5449
σ(X) = 3√67

数値を変換したら、平均と散らばりは？

Y = aX + b公式理由
期待値E(Y) = aE(X) + b全体をa倍してbだけ移動
分散V(Y) = a²V(X)ずれを2乗するからa²倍
標準偏差σ(Y) = |a|σ(X)長さなので負にならない

ここがポイントE(X²) と {E(X)}² は別物。X²を平均したものと、平均してから2乗したものを混同しない。bを足しても散らばりは変わりません。

04

独立：別々の結果を組み合わせる

独立とは、一方の結果を知っても、もう一方の確率が変わらないこと。

独立の判定：P(AかつB) = P(A)P(B)。例えば別々に投げる公平なサイコロとコインは、通常、独立と考えます。

列はサイコロ1〜6。上段が表、下段が裏。緑は条件に合う組。

求めたい量公式使える条件
和の期待値E(X + Y) = E(X) + E(Y)不要
積の期待値E(XY) = E(X)E(Y)独立なら使える
和・差の分散V(X ± Y) = V(X) + V(Y)独立なら使える
aX + bY の分散a²V(X) + b²V(Y)独立なら使える
「戻す」と「戻さない」の違い

球を戻して、よく混ぜてから次を引くなら、次の袋の中身は同じ。繰り返しは独立と考えられます。戻さずに次を引くと、袋の中身が変わるため、一般に独立ではありません。

ただし、1回に3個同時に引いて全部戻す試行を2回行うなら、1回目の個数と2回目の個数は独立です。

ここがポイント「別の文字X、Yだから独立」とは限りません。独立でなくても期待値の和は使えます。分散の差は、独立なら引き算でなく足し算。

小さな確認　戻さずに2枚引いた数をX、Yとする。必ず使えるのは？

05

二項分布：成功した回数を数える

同じ成功確率pの試行を、独立にn回。その成功回数Xを数える。

「成功」は問題で決めた結果のこと。表、赤球、当たりなど、好きな結果を成功と呼べます。

X は B(n, p) に従う
P(X = k) = nCkpk(1 − p)n−k
E(X) = np　　V(X) = np(1 − p)
  1. 何を「1回の試行」にするか決める。
  2. 1回で成功する確率 p と、繰り返す回数 n を分ける。
  3. 成功k回の並べ方 nCk × 1つの並びの確率 pᵏ(1−p)ⁿ⁻ᵏ。
例題：「コイン4枚で表1枚」を3回試す

1回の試行は「コイン4枚を投げること」。表が1枚の確率は 4C1(12)⁴ = 14。これを3回繰り返すので、成功回数は B(3, 14)。

P(X = 2) = 3C2(14)²(34) = 964

ここがポイント「球を同時に数個取り出す」は、その中の成功が独立ではないため、そのまま二項分布にはできません。戻すかどうか、何を1回とするかが出発点。

06

連続型：確率はグラフの面積

待ち時間のように細かく値が変わるときは、棒から「面積」へ。

確率密度 f(x)は面積を作るための高さ。P(a ≦ X ≦ b) は a から b までのグラフの下の面積です。全体の面積は1。

端を交差させたときは、もう一方を合わせます。

  1. 長方形なら「幅 × 高さ」。12分おきの待ち時間は f(x) = 112（0 ≦ x ≦ 12）、それ以外は0。
  2. f(x) = x2 の0からtまでなら、三角形の面積 t × t22 = t²4。
  3. aからbまでなら「0からbまで」−「0からaまで」。数学Ⅱの積分でも同じ面積を求められます。
連続型の平均・分散も、考え方は同じ
E(X) = ∫ x f(x) dx
E(X²) = ∫ x² f(x) dx
V(X) = E(X²) − {E(X)}²

∫（積分）は細い面積を全部足す記号。計算に慣れる前は、図形の面積や次の一様分布の公式で進めます。

一様分布 [a, b]： E(X) = a + b2、V(X) = (b − a)²12

例えば [1,8] なら E(X)=4.5、V(X)=4912。

ここがポイント連続型では P(X = 3) = 0。1点には横幅がないためです。f(3) が0でなくても、「高さ」と「確率」は違います。

小さな確認　12分おきの電車。7分以上待つ確率は？

07

正規分布：平均からの距離に直す

正規分布は左右対称の山。平均から何個分の標準偏差だけ離れたかで読む。

N(μ, σ²)の1つ目は平均、2つ目は分散。N(25,4)なら平均25、標準偏差2です。
Z = X − μσ　→　Z は N(0,1) に従う

平均25・標準偏差2の山。区間を動かして、面積を確かめよう。

  1. まず σ = √分散 を求める。
  2. X の上下の境目を、それぞれ (境目 − μ) ÷ σ に直す。
  3. 標準正規分布表を読み、必要な面積を足す・引く。

このサイトの正規分布表は「0からzまで」

下の A(z) は、z ≧ 0 に対して P(0 ≦ Z ≦ z)。表の数をそのまま左側全部の確率にしないこと。

範囲計算例
0〜zA(z)0〜1.5：0.4332
z以上0.5 − A(z)1.5以上：0.0668
−z〜0A(z)−1.5〜0：0.4332
−a〜bA(a) + A(b)−2.5〜1.5：0.9270
逆向きの問題：確率から境目を探す
  1. N(50,25) で右側の確率が0.25。標準偏差は5。
  2. 0からzの面積は 0.5 − 0.25 = 0.25。表で0.25に近い値を探すと z ≈ 0.67。
  3. X = μ + σZ に戻し、a ≈ 50 + 5×0.67 = 53.35。

ここがポイント負のzは左側。左右対称なので、まず正の距離で表を引き、図でどの面積か確認します。表の丸め方で末尾が少し変わります。

小さな確認　XがN(25,4)に従う。X=28を標準化すると？

08

二項分布を正規分布で近似する

繰り返しが多い二項分布の棒は、正規分布の山で近似できる。

B(n,p) ≈ N(np, np(1−p))
Z = X − np√{np(1−p)}

npとn(1−p)がともに十分大きいときに使います。この章の問題では十分大きい設定です。

例題：コイン2500回で、表が1320回以上
  1. Xを表の回数とする。XはB(2500, 12)。
  2. 平均は1250、分散は625、標準偏差は25。
  3. 境目を標準化：(1320−1250)÷25 = 2.8。
  4. P(X ≧ 1320) ≈ P(Z ≧ 2.8) = 0.5 − 0.4974 = 0.0026。約0.26%。
連続補正：回数を滑らかな面積で置き換えるとき、X≧1320を1319.5以上とすると精度を改善できます。本教材の問題解説は学校の表を用いる基本計算（補正なし）を先に示し、必要な箇所で補足します。

ここがポイント近似なのに「=」で完全に同じとしないこと。平均と分散を先に計算し、分母は必ず標準偏差にします。

小さな確認　B(1000,0.1)を正規近似すると？

09

標本調査：一部から全体を考える

調べたい全体が母集団。その一部として選んだものが標本。

無作為抽出は、都合のよい相手を選ばず、対象からランダムに選ぶこと。人数だけ増やしても、選び方の偏りは消えません。
ことば意味
母平均 μ・母標準偏差 σ全体の平均と散らばり
標本の大きさ n選んだ人数・個数
標本平均 X̄選ばれるn個の平均。標本を変えると値も変わる
標本平均の観測値 x̄実際に調べて得られた平均の数値
X̄ = X₁ + … + Xₙn
E(X̄) = μ　　V(X̄) = σ²n　　σ(X̄) = σ√n

紫：個々の値（σ=3）。緑：n個の標本平均。曲線は見比べやすいよう、それぞれ山の高さをそろえています。

なぜ標準偏差を√nで割る？
  1. 独立なn個の和の分散は nσ²。
  2. 平均は和をnで割るため、分散はn²で割る。nσ² ÷ n² = σ²n。
  3. 平方根を取ると σ√n。この標本平均の標準偏差を標準誤差とも呼びます。

母集団が正規分布なら、標本平均も正規分布。そうでなくても、独立な同じ分布からの標本でnが十分大きければ、標本平均を正規分布で近似できます。

ここがポイントここでの公式は独立な抽出（復元抽出、または母集団が十分大きい場合）を前提にします。σとσ√nは「個人の散らばり」と「平均の散らばり」で別物。

小さな確認　標本を25人から100人に増やすと、平均の標準誤差は？

10

推定：平均や割合を幅で答える

1つの数で決めつけず、「この範囲」と答えるのが区間推定。

標本平均のまわりに「誤差の幅」を付けます。95%信頼区間では、標準誤差を1.96倍した幅を左右に付けます。

母集団が正規分布でσが既知の場合、または十分大きい標本による正規近似で使う式です。

母平均の95%信頼区間： x̄ ± 1.96 × σ√n
σが不明でnが十分大きいとき：σを標本の標準偏差sで近似

標本平均65.4、標準偏差7.2として比較。nが小さい設定は「幅の変わり方」の説明用です。

添付問題の例：n=100、平均65.4、標準偏差7.2
  1. 標準誤差：7.2 ÷ √100 = 0.72。
  2. 誤差の片幅：1.96 × 0.72 = 1.4112。
  3. 下端63.9888、上端66.8112。小数第3位を四捨五入すると [63.99, 66.81]。

割合を推定するとき

p̂（ピー・ハット）は標本の成功割合。「成功した個数 ÷ 調べた個数」です。

母比率の95%信頼区間：p̂ ± 1.96√{p̂(1−p̂)n}

この正規近似はnが十分大きく、成功・失敗の両方が十分あるとき。小標本・0や1に近い割合では別の方法が必要です。

必要な人数を決める：区間の全幅を0.02以下にしたい
  1. 割合を0.5と見積もる。全幅は「片幅の2倍」。
  2. 2 × 1.96√{0.5×0.5n} ≦ 0.02。
  3. √n ≧ 98 なので n ≧ 9604。人数は整数なので端数が出たら切り上げます。

ここがポイント95%とは、この方法で標本を取り直して区間を作ると、約95%の区間が真の値を含むという意味。個々のデータの95%が入る範囲ではありません。

小さな確認　区間の「全幅」が0.02。左右それぞれの片幅は？

検定：偶然では説明しにくい？

「もとの仮定が正しい」として、今回のずれがどれほど珍しいかを調べる。

棄却（ききゃく）は、仮定H₀を採用しないという判断。有意水準5%は、H₀が正しいのに誤って棄却する確率を5%に設定することです。正規分布では、両側に2.5%ずつ残す境界が±1.96、右だけに5%残す境界が約1.645です。

添付の最後の2題を解くための章です。「平均との差がある」と「偶然の範囲を超える差がある」を区別します。

  1. 帰無仮説（きむかせつ）H₀を置く。「母平均140g」「母比率0.30」など、いったん正しいとする値。
  2. 対立仮説（たいりつかせつ）H₁を決める。「違う」なら両側、「大きい」なら上側。データを見る前に決める。
  3. 標準化して、ずれZを求める。
  4. 有意水準5%の境界と比べる。両側なら|Z|≧1.96、上側ならZ≧1.645を目安にH₀を棄却する。
状況標準化
母平均の検定（σ既知、または大標本近似）x̄ − μ₀s√n（σ既知ならsをσに）
母比率の検定p̂ − p₀√{p₀(1−p₀)n}

緑が「まれな領域」。橙の線が今回のZです。

例題：ハンバーガーは平均140gより重い？
  1. H₀：μ=140、H₁：μ>140。上側検定を使う。
  2. n=121、x̄=141.2、s=7.2。標準誤差は 7.2÷11。
  3. Z = (141.2−140) ÷ (7.2÷11) ≈ 1.83。
  4. 1.83 > 1.645。5%水準でH₀を棄却し、母平均は140gより大きいと判断する。大標本の正規近似での判断。

ここがポイント棄却できない＝「同じと証明された」ではありません。今回のデータでは違いを示す証拠が足りない、という意味です。割合の検定では分母にp̂ではなく、仮定したp₀を使います。

小さな確認　「140gより重いか」を5%で調べる。使う境界は？

  2. 標準誤差は7.2÷11。Z=(141.2−140)÷(7.2÷11)=116≈1.83。
  3. 上側5%の境界1.645（表なら約1.64〜1.65）より1.83は大きい。H₀を棄却。
  4. 両側の境界1.96を使うと結論が変わる。問題の「より重い」に合わせる。

問題を解くときのポイント

  1. 何を数えているかを一文で書く。「Xは表の回数」「X̄は49個の平均」など。
  2. 離散か連続か、独立か、戻すかを確認する。
  3. 平均・分散・標準偏差を分けて計算し、次の表から公式を選ぶ。
  4. 確率は0〜1、分散は0以上かを確認。近似と丸めは最後に行う。
