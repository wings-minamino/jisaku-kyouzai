二次関数ラボ

数学Ⅰ ／ 第3章 2次関数

二次関数ラボ²

スライダーを動かすと、グラフがその場で変わります。式の数字とグラフの形がどう結びつくかを、目で見て確かめましょう。最後に問題を解くときのポイントをまとめています。

1y = ax² 2平行移動 3平方完成 4最大・最小 5x軸との共有点 62次不等式 7解き方のポイント
01

y = ax² の形

a の符号で向き、a の大きさで開き具合が決まる。

ここがポイント点線は基準の y = x²。x = 1 のとき y = a になるので、点 (1, a) を目印にすると形がすぐ描けます。

02

平行移動：y = a(x − p)² + q

y = ax² を x 方向に p、y 方向に q 動かすと、頂点が (p, q) に移る。

ここがポイント( ) の中が x − 3 なら頂点の x 座標は +3、x + 3 なら −3。符号が逆に見えるのは「x に 3 を入れると 0 になる」位置が頂点だからです。

03

平方完成

y = ax² + bx + c を y = a(x − p)² + q に直すと、頂点と軸が読める。

    04

    定義域がある場合の最大・最小

    軸と区間の位置関係で答えが変わる。動かして「場合分けの境目」を探そう。

    最小値の場合分け

    軸が区間より左 → 左端軸が区間の中 → 頂点軸が区間より右 → 右端

    最大値の場合分け（区間の中央と比べる）

    軸が中央より左 → 右端軸＝中央 → 両端軸が中央より右 → 左端
    05

    x 軸との共有点と判別式

    D = b² − 4ac の符号で、グラフが x 軸と何回交わるかがわかる。

    D > 0：2 点で交わるD = 0：1 点で接するD < 0：共有点なし

    ここがポイントb が偶数（b = 2b′）なら D/4 = b′² − ac を使うと計算が楽。この例では D/4 = 1 − ac。

    06

    2 次不等式

    グラフが x 軸より上（または下）にある x の範囲が答え。

    ここがポイントx² の係数が負なら、まず両辺に −1 を掛けて正にする（不等号の向きが逆になる）。そのあと「> 0 は外側、< 0 は内側」。

    07

    問題を解くときのポイント

    どの問題も「式 → 図 → 読み取り」の順で考えるとぶれない。

    1. 平方完成する頂点と軸を出す
    2. グラフを描く向き・頂点・y 切片
    3. 条件を書き込む定義域・x 軸・区間の中央
    4. 図から読み取る文字があれば場合分け

    平方完成

    • x² の係数 a で、x の項までをくくる
    • x の係数の半分の 2 乗を足して引く
    • { } を外すとき、引いた数に a を掛ける

    ミス注意：a を掛け忘れて定数項がずれる

    頂点・軸の読み方

    • y = a(x − p)² + q → 頂点 (p, q)、軸 x = p
    • (x + 2)² なら p = −2
    • a > 0 で下に凸、a < 0 で上に凸

    ミス注意：( ) の中の符号をそのまま頂点にしてしまう

    最大・最小（定義域あり）

    • 下に凸なら、最小は「軸が区間の左・中・右」の 3 通り
    • 最大は「軸が区間の中央より左・右（一致）」で分ける
    • 上に凸なら最大と最小の考え方が入れ替わる
    • 必ず図を描き、端点と頂点の y 座標を比べる

    x 軸との共有点

    • D = b² − 4ac
    • D > 0：2 個 ／ D = 0：1 個（接する） ／ D < 0：0 個
    • b が偶数なら D/4 = b′² − ac
    • 「x 軸と接する」は D = 0 と同じ意味

    2 次不等式

    • x² の係数を正にそろえる
    • = 0 の解 α < β を求める
    • > 0 → x < α, β < x（外側）
    • < 0 → α < x < β（内側）
    • D ≦ 0 のときは「すべての実数」「解なし」などになるので図で確認

    式の決め方（3 つの型）

    • 頂点・軸がわかる → y = a(x − p)² + q
    • 通る 3 点がわかる → y = ax² + bx + c で連立
    • x 軸との交点 (α, 0), (β, 0) → y = a(x − α)(x − β)

    グラフの移動（式の置き換え）

    移動置き換え頂点 (p, q) の行き先
    x 方向に s、y 方向に t 平行移動x → x − s, y → y − t(p + s, q + t)
    x 軸に関して対称移動y → −y(p, −q)　※向きも逆
    y 軸に関して対称移動x → −x(−p, q)
    原点に関して対称移動x → −x, y → −y(−p, −q)　※向きも逆

    迷ったら、頂点だけ動かして a の符号（向き）を決める方法が確実です。
